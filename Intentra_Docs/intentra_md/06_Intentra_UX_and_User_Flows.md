**Intentra --- UX & User Flows**

*Intentra*

Version: September 2026

# 1. UX Principle

The interface should feel like normal commerce. Blockchain, adjudication
infrastructure and internal policy engines remain invisible unless
relevant to the user.

# 6. Complaint Flow

1.  Select transaction.

2.  Describe problem in natural language or choose a category.

3.  System retrieves transaction context.

4.  User adds evidence.

5.  Intentra assesses the issue.

6.  Provider receives a response request where appropriate.

7.  Resolution is proposed or escalated.
