**Intentra --- Product Roadmap**

*Intentra*

Version: September 2026

# 1. Phase 0 --- Prototype

-   Natural-language intent

-   Provider profiles

-   Recommendation + alternatives

-   Authorization

-   Agreement

-   Moove payment-link integration

-   Basic fulfillment

-   Evidence

-   Basic complaints

-   Transaction history

# 2. Phase 1 --- Pilot

-   Real providers

-   Real users

-   Real Moove transactions

-   Provider dashboard

-   Customer support

-   Resolution rules

-   Trust signals

-   Operational analytics

# 3. Phase 2 --- Assurance

-   Outcome engine

-   Advanced evidence

-   AI-assisted resolution

-   Selected GenLayer adjudication

-   Refund workflows

-   Provider performance scoring

# 4. Phase 3 --- Business Procurement

-   Business organizations

-   Teams

-   Approval policies

-   Vendor management

-   Quote collection

-   Budget controls

-   Procurement analytics

# 5. Phase 4 --- External Agent Infrastructure

-   Transaction Assurance API

-   Agent SDK

-   Scoped agent permissions

-   External marketplace integrations

-   MCP/A2A interfaces

-   Trust API

# 6. Phase 5 --- Scale

-   Additional countries

-   Additional categories

-   Higher transaction limits

-   Enterprise contracts

-   Agent-to-agent commerce

# 7. Prioritization Rule

Every new feature should strengthen one of four things: transaction
volume, transaction reliability, transaction accountability, or reusable
infrastructure. Avoid features that only make the demo look more
futuristic.
