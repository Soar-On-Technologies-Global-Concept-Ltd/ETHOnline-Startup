# 1. Research Purpose

This document records the strategic hypothesis and competitive landscape
used to position Intentra. Competitive claims should be revalidated
before external publication.

# 2. Core Hypothesis

Discovery, agent identity, payment authorization and agentic checkout
are increasingly competitive areas. A potentially stronger
differentiation is outcome assurance: proving whether an AI-initiated
transaction matched the user\'s authorized intent and agreed
fulfillment, then resolving deviations.

# 4. Key Competitor Lesson

A generic \'AI marketplace + payment + escrow\' proposition is not
sufficiently differentiated. Intentra must make the transaction
lifecycle itself the product.

# 5. Validation Questions

-   Do users care about post-payment accountability enough to change
    behavior?

-   Will providers accept evidence and dispute workflows?

-   Can outcome verification work reliably for services?

-   Which categories produce enough repeat transactions?

-   Will businesses pay for transaction assurance as infrastructure?

-   Which assurance APIs are most valuable to external agents?

# 6. Research Discipline

Treat the white-space thesis as a hypothesis until validated through
interviews, transaction data, dispute analysis and competitor
monitoring.
