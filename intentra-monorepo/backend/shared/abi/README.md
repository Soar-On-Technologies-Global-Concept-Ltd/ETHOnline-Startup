# shared/abi

`IntentraEscrow.json` is the canonical ABI, vendored from `intentra-monorepo/contracts/exports/intentra-contracts.ts`.
The escrow itself lives in `intentra-monorepo/contracts/` and is owned by the contracts team; the Solidity that
used to sit under `backend/contracts/` was superseded by it and has been deleted.
